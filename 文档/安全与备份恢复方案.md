# 安全与备份恢复方案（业务线1及组长整合素材）

## 已实现与适用边界

- 身份认证：演示账号SHA256(盐+密码)；每个账号行加锁更新失败次数，连续5次失败提交锁定10分钟，不能因抛业务错误回滚计数；成功登录清零并更新last_login。演示种子盐固定且公开、密码为123456，只供本地课程展示。
- 会话：Flask签名Cookie，HttpOnly、SameSite=Lax，30分钟无活动超时；不是服务端会话存储。正式部署必须设置随机APP_SECRET_KEY，HTTPS下启用SESSION_COOKIE_SECURE，并改用可撤销的服务端会话及CSRF令牌。
- RBAC：社区可管理档案/评估/计划；监管只读；家属每个详情/历史/计划接口校验绑定elder_id，列表服务端强制按绑定过滤；护工/机构负责人不得访问档案模块。前端隐藏按钮不作为权限依据。
- 数据展示：身份证始终在服务端拼接为前6+8个星号+后4位，不把原值发给前端；监管接口电话脱敏并移除详细住址；社区及绑定家属可看必要联系人信息。
- 参数化：所有DAO值通过驱动参数绑定，动态字段来自代码常量，报表名来自固定白名单；文本输出经过HTML转义；异常响应不返回SQL、身份证或连接配置。
- 事务完整性：重复身份证由唯一约束兜底；档案逻辑注销，不删除历史；批量写入与多表修改整体提交/回滚；重叠计划由统一老人行锁串行化。应用用户不可绕过DAO直接写计划。

## 部署前应完成的安全配置（方案，不声称已在演示库实施）

1. 把演示SHA256升级为Argon2id/scrypt等密码派生算法，使用随机盐；重设演示密码和APP_SECRET_KEY，不记录密码、盐或完整身份证。不得将config_local.py、数据库备份或密钥加入Git。
2. 应用使用独立数据库账号，授予业务必需的SELECT/INSERT/UPDATE/DELETE以及指定例程EXECUTE；无DROP DATABASE/ALTER/CREATE USER/FILE等权限。迁移、备份、事件调度分别使用独立受控账号。业务用户只能通过API写库。
3. 限制数据库监听地址，跨主机用TLS；磁盘/备份加密。敏感字段如需列加密，采用应用侧AES-GCM和外置密钥管理，身份证唯一查重用带密钥HMAC指纹单独建唯一索引；密文随机IV不能直接承担唯一查重。密钥轮换须同时迁移指纹，不能把密钥与密文存同表。当前演示库身份证仍为明文，仅实现展示脱敏。
4. 加入CSRF令牌、登录限速和安全审计：记录操作者、操作类型、对象编号、时间和结果，不记录原身份证/电话/登录密码。当前版本未实现完整审计日志、字段加密或全局撤销会话，报告中需如实说明。
5. 定期复核账号绑定和角色权限；监管当前沿用演示系统全局监管权限，社区管理员亦为全局管理员。若需按辖区隔离，先增加用户授权社区关系，不应仅在页面筛选社区。

## 备份计划

课程演示建议目标：RPO≤15分钟、RTO≤2小时（目标值，需演练测量）。每天02:00执行一次全量逻辑备份，启用ROW格式binlog并每15分钟将已封存日志复制到独立存储；全量保留7日、周备份保留4周。备份加密并限制下载权限，至少保留一份异机副本。

使用独立凭据配置（例如mysql_config_editor管理的login-path），不要把密码写进命令或脚本：

```bash
mysqldump --login-path=elder_backup --single-transaction --routines --triggers --events --hex-blob --set-gtid-purged=OFF elder_care > /secure-backups/elder_care-full.sql
```

备份期间避免DDL变更。MySQL 8/9按版本配置binlog保留和归档，记录备份时间及对应binlog位置/GTID。全量备份包含敏感明文，文件自身必须加密；单独保存校验和、schema版本与恢复说明。日志归档使用受控运维任务，不在本仓库保存运行密码。

## 恢复与演练

1. 在隔离实例恢复全量备份，停用事件调度，检查备份文件校验和。导入命令使用受控login-path；不要向正常演示库直接覆盖。
2. 按记录的binlog起点重放到目标故障前时刻。删除误操作或逻辑错误的恢复点需由管理员确认，不能盲目重放所有日志。
3. 校验表数/行数、外键和唯一约束、视图及例程是否存在；查看事件DEFINER是否仍有效，重启每小时暂停计划事件。
4. 执行档案创建、查询脱敏、一次评估+计划事务、一次故意失败回滚、重复身份证拒绝、家庭隔离；检查SQL结果与备份基准一致。
5. 记录实际数据丢失窗口与恢复耗时，对比RPO/RTO；每月至少演练一次，课程提交前至少完成一次并保存真实记录。当前会话没有数据库环境，未执行备份恢复演练，不能填写“已达标”。
